# 자유의 여신상 AR 설명판 (Season3 AR Plus)

현실 공간에 나타나는 디지털 안내판. 스마트폰 또는 태블릿의 카메라로 자유의 여신상 인식 이미지를 비추면 AR 설명판이 표시되는 이미지 인식형 콘텐츠입니다.

## 실행 주소

- 체험: https://imm-content.github.io/season3-ar-plus/
- 저장소: https://github.com/imm-content/season3-ar-plus

## 체험 방법

1. 스마트폰 또는 태블릿에서 QR코드나 실행 주소로 접속합니다.
2. 카메라 사용 권한 요청이 나타나면 허용합니다.
3. 자유의 여신상 인식 이미지를 카메라에 비춥니다.
4. 이미지 위에 나타나는 AR 설명판을 확인합니다.
5. 체험을 마치면 해당 브라우저 탭을 닫습니다.

## 주요 파일

| 파일 | 설명 |
|---|---|
| `index.html` | AR 화면, 카메라 실행 및 상태 관리 |
| `targets.mind` | MindAR 이미지 인식 대상 데이터 |
| `panel.png` | AR 설명판 이미지 |
| `README.md` | 콘텐츠 소개 및 실행 안내 |

## 사용 기술 및 실행 환경

- HTML, CSS, JavaScript
- A-Frame 1.5.0
- MindAR 1.2.5 (이미지 인식 AR)
- HTTPS, 카메라 사용 권한, 인터넷 연결 및 해당 기술을 지원하는 브라우저 필요
- Android에서는 Chrome 또는 삼성 브라우저를 이용할 수 있으나 기기와 브라우저 버전에 따라 실행 결과가 다를 수 있습니다.

## 카메라 안정성 개선 (2026-11-25)

- MindAR 자동 시작 대신 페이지 초기화 후 명시적으로 실행합니다.
- `arReady`, `arError` 이벤트를 이용하여 실행 상태를 관리합니다.
- 초기화가 60초를 초과하면 오류 안내와 재실행 버튼을 표시합니다.
- 재실행 버튼은 기존 카메라 연결 해제를 시도한 뒤 페이지를 새로고침합니다.
- 페이지 이탈(`pagehide`) 시 MindAR 종료 및 영상 스트림 트랙 해제를 시도합니다.
- 뒤로 가기 등으로 캐시된 페이지가 복원되면 새로고침합니다.
- 기존 인식 대상, 설명판 이미지, 크기와 위치, 실행 주소는 유지합니다.

## 오류 발생 시 조치

1. 브라우저와 해당 사이트의 카메라 권한을 확인합니다.
2. 오류 안내가 나타나면 **카메라 다시 실행** 버튼을 누릅니다.
3. 문제가 지속되면 다른 카메라 사용 앱이나 브라우저 탭을 닫고 다시 접속합니다.
4. 다른 브라우저로 접속하거나, 필요한 경우 스마트폰을 재부팅합니다.
5. 반복 실패 시 기종, 브라우저, 실행 순서 및 오류 메시지를 기록합니다.

## 검증 계획

- Galaxy Wide5 및 Galaxy A36 5G에서 최초 실행과 10회 반복 실행
- 다른 AR·MR 콘텐츠 체험 후 재접속
- 이미지 인식 및 설명판 표시 확인
- 초기화 실패 시 오류 안내 및 재실행 확인

현재 개선본의 실제 기기별 반복 실행 검증은 완료되지 않았습니다. 모든 기종의 정상 작동을 보장하지 않으며, 카메라 장애의 근본 원인은 추가 검증이 필요합니다.

## GitHub Pages 반영

기존 파일을 백업한 후 `index.html`과 `README.md`를 저장소에 반영합니다. `targets.mind`와 `panel.png`는 기존 파일을 유지합니다. 배포 완료 후 기존 실행 주소와 QR코드로 테스트합니다.

## 후면 카메라 자동 대체 실행 (2026-11-26)

- 기존 MindAR 카메라 요청이 실패하면 브라우저의 카메라 목록을 조회하고 개별 deviceId로 재시도합니다.
- 기본 해상도 우선, 실패 시 640×480 / 15fps 선호 조건을 사용합니다.
- 후면 방향이 확인된 스트림만 AR에 전달하며 전면 카메라는 탐색용으로만 잠시 사용될 수 있습니다.
- 기종명이나 camera 0 등의 번호를 고정하지 않습니다.
- 독립 진단 V2에서 A36 5G의 camera 2 실패 및 camera 0 반복 성공을 확인했습니다. 이 AR 개선본 자체는 실제 기기 검증 전입니다.
- 브라우저가 카메라 방향 정보를 제공하지 않거나 모든 후면 장치가 실패하면 실행되지 않을 수 있습니다.

### 우선 검증

1. A36 5G에서 기존 주소로 접속하여 후면 영상과 설명판 인식을 확인합니다.
2. 탭을 닫고 다시 접속하는 과정을 3회 반복합니다.
3. Wide5와 Z Flip5에서도 동일하게 확인합니다.
4. 실패 시 화면의 오류 메시지를 기록합니다.
